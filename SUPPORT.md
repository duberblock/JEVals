# Support

## Where to ask

- **Bugs and concrete defects** → open an issue using the *Bug report* form
  ([Issues](../../issues)).
- **New features or protocol/provider support** → open an issue using the
  *Feature request* form.
- **Usage questions, architecture discussion, "how do I…"** → GitHub
  [Discussions](../../discussions) if enabled on this repository; otherwise
  open a question issue and we will route it.

Before opening an issue, please:

1. Search existing issues — duplicates are closed with a pointer.
2. Check the [README](README.md) for setup and the in-app **Settings** guides,
   which document every provider box, the expected endpoints, and the tested
  provider matrix.
3. For local runs, include the relevant execution ID or the evidence tab
   content — never paste API keys.

## Response expectations

This is a maintainer-driven project; responses are best-effort. Bug reports
with a minimal reproduction and the gates' output get prioritized.

## Contributing fixes

Found the answer yourself and want to improve the docs? Pull requests that
clarify the README, the Settings guides, or this file are welcome — see
[CONTRIBUTING.md](CONTRIBUTING.md).
